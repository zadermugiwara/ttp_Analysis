\section{Purpose and Scope}

This document records the complete local workflow used to revise the vector-like
top-partner recoil-mass study in response to the review.  The active revision
package is \rev{} inside the repository \repo{}.  Older manuscript directories
such as \texttt{Paper/} and \texttt{VLQ\_SingleT\_CLIC\_Paper/} are treated only
as references.

The workflow separates three levels of result:
\begin{enumerate}
  \item legacy and idealized recoil studies imported from the reviewed inputs;
  \item ISR-only and polarization stress tests generated locally;
  \item fresh CLIC luminosity-spectrum production with a parametric
        $\gamma\gamma\to$ hadrons overlay stress test.
\end{enumerate}

The present workflow does not claim a full GEANT4/CLICdet detector projection.
Detector response is still a custom FastJet-based, fast/parametric treatment.
The remaining JHEP-readiness items are listed in Section~\ref{sec:remaining}.

\section{Inputs and Assumptions}

The reviewed PDF copied into \rev{} is the manuscript source of truth for the
revision narrative.  The current local inputs include:
\begin{itemize}
  \item imported baseline and polarization scan CSVs:
        \texttt{data/kappa\_baseline.csv},
        \texttt{data/kappa\_plus80ISR.csv}, and
        \texttt{data/kappa\_minus80ISR.csv};
  \item width inputs from the older paper directory;
  \item MG5/MadSpin/Pythia8 event samples generated locally;
  \item FastJet reconstruction outputs in \texttt{ttp\_AnalysisISR};
  \item $\sqrt{s'}$ diagnostics computed directly from LHE incoming particles.
\end{itemize}

The nominal luminosity for yield scaling is $5~\mathrm{ab}^{-1}$.  The nominal
analysis fiducial choice is $|\eta|<2.5$ for reconstructed objects.  Legacy plots
from the reviewed version are explicitly labeled as legacy $|\eta|<5$ inputs
until regenerated.

\section{\texorpdfstring{$\sqrt{s'}$}{sqrt(s prime)} Diagnostic}

\subsection{Purpose}

The recoil mass in the analysis is computed using nominal
$\sqrt{s}=3~\mathrm{TeV}$.  ISR and beamstrahlung reduce the event-by-event
effective collision energy $\sqrt{s'}$, broadening the recoil shape and shifting
the inferred recoil mass.  The diagnostic reads incoming LHE particles and
computes:

\[
  \sqrt{s'} = \sqrt{(p_{e^-}+p_{e^+})^2}.
\]

\subsection{Running From a Manifest}

For the fresh CLIC production:

\begin{lstlisting}
python3 JHEP_Revised/tools/run_sqrt_s_prime_from_manifest.py \
  --manifest JHEP_Revised/logs/production_manifest_clic3000ll_fresh.csv \
  --out-dir JHEP_Revised/data/sqrt_s_prime_clic3000ll_fresh_nev10000 \
  --fig-dir JHEP_Revised/figs/sqrt_s_prime_clic3000ll_fresh_nev10000
\end{lstlisting}

The main output is:

\begin{lstlisting}
JHEP_Revised/data/sqrt_s_prime_clic3000ll_fresh_nev10000/sqrt_s_prime_summary.csv
\end{lstlisting}

\section{Profile-Likelihood Closure}

\subsection{Motivation}

The reviewed manuscript used $S/\sqrt{S+B}$ as the main sensitivity metric.
The revision keeps that number as a transparent diagnostic and adds an Asimov
binned profile-likelihood closure.  The local RooStats path had previously
returned an invalid zero-nuisance discovery result, so the manual binned
profile-likelihood implementation is treated as authoritative and RooStats is
kept only as an optional diagnostic.

\subsection{Representative Command}

For the unpolarized $m_T=1.2~\mathrm{TeV}$ fresh CLIC sample, the validated
closure command is:

\begin{lstlisting}
python3 vlq_recoil_discovery.py \
  --signal ttp_AnalysisISR/root/Tt1200ISR_clic3000ll_nev10000_fresh.root \
  --background \
    ttp_AnalysisISR/root/ttbarISR_clic3000ll_nev10000_fresh.root \
    ttp_AnalysisISR/root/tthISR_clic3000ll_nev10000_fresh.root \
    ttp_AnalysisISR/root/ttzISR_clic3000ll_nev10000_fresh.root \
    ttp_AnalysisISR/root/w_w-zISR_clic3000ll_nev10000_fresh.root \
  --hist mrecoil_BDT1200_cut \
  --rebin 100 \
  --scale-from-xsec \
  --lumi 1 \
  --signal-xsec 178.218 \
  --background-xsec 9285.83 217.889 721.333 53.329 \
  --background-norm-unc 0.05 \
  --outdir JHEP_Revised/validation/profile_clic_unpol_rebin100/Tt1200
\end{lstlisting}

The four unpolarized mass points were run with mass-matched BDT recoil
histograms and $100~\mathrm{GeV}$ bins.  This binning avoids empty-background
template bins that artificially inflate the unrebinned profile likelihood.

The profile summary is:

\begin{lstlisting}
JHEP_Revised/validation/profile_clic_unpol_rebin100_summary.csv
\end{lstlisting}

\section{Quality Checks}

The current workflow checks the following:
\begin{itemize}
  \item queue statuses are recorded in CSV files and can be resumed;
  \item manifests require completed MG5 jobs and decompressed HepMC files;
  \item reconstruction cutflows are regenerated from reconstruction output files;
  \item yield tables are generated from CSV files, not hand-entered numbers;
  \item $\sqrt{s'}$ diagnostics are computed from LHE incoming particles;
  \item one-BX overlay is reconstructed separately from clean samples;
  \item profile-likelihood closure verifies that
        $Z_{\mathrm{PLR}}^{\mathrm{Asimov}}$ agrees with the binned Cowan
        calculation after $100~\mathrm{GeV}$ rebinning;
  \item the manuscript compiles with \texttt{latexmk}.
\end{itemize}

\section{Known Limitations and Remaining Work}
\label{sec:remaining}

The remaining tasks before a final JHEP-level reach claim are:
\begin{enumerate}
  \item continue using fresh Expansion project directories for future MG5 runs;
        the old reused NTFS project directories remain suspect;
  \item regenerate legacy figures with the nominal $|\eta|<2.5$ reconstructed
        object acceptance;
  \item include or bound W-fusion single-top and high-mass $V+$jets backgrounds;
  \item replace truth b-subjet matching with calibrated b-tag efficiency and
        mistag parameterizations;
  \item produce forced-decay validation samples for
        $T\to Wb$, $T\to Zt$, and $T\to Ht$;
  \item run at least one full-matrix-element finite-width/interference stress
        test near $\Gamma_T/m_T=10\%$;
  \item add a detector-performance table for top-tag and b-tag efficiencies
        versus jet $p_T$, mass, and $\eta$.
\end{enumerate}
